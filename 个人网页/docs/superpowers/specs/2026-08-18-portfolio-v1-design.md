# 个人作品集网站 V1 设计说明

> 目标：可运行、可预览的基础版本。后续根据用户提供的截图与参考网站持续优化。

## 定位与气质

- 身份：视觉设计师 / AI 设计师 / 品牌设计师。
- 视觉：暗色系、高级、克制、科技感；避免模板感。
- 基调：近黑底色 + 暖白文字 + 低饱和紫青点缀；等宽字体做索引与标签；
  细线、网格、噪点、克制的光晕；中文大字号排版。

## 技术

- React 19 + Vite 7，pnpm 管理依赖。
- 版心：`max-width: 1700px`，两侧 `clamp` 留白。
- 无第三方 UI 库，全部样式手写 CSS（设计变量 + 组件级样式）。
- 滚动进场：自写 IntersectionObserver hook，尊重 `prefers-reduced-motion`。

## 页面结构

1. **Hero（全屏）**：动画背景（当前为程序生成 WebP 占位，预留 `<video>` 切换）、
   大标题「方昱 / FANG YU」、导航栏、联系按钮、底部元信息与滚动提示。
2. **个人经历**：Monogram 头像占位、个人介绍、学历时间线、联系方式、项目数据。
3. **精选项目**：3 张大卡片，程序化抽象占位视觉，预留真实作品替换位。
4. **个人优势**：4 张能力卡片（视觉 / AI / 品牌 / 技术协同）。
5. **底部联系（全屏收尾）**：大标题 CTA、邮件/电话/QQ、社交占位与页脚。

## 数据

全部文案集中在 `src/data/site.js`，姓名、联系方式来自简历；作品、数据为占位，待用户替换。
